# OCTA DEVS CRM

Employee portal, CRM, and website admin for OCTA DEVS.

## Run

```bash
npm install
npm run dev
```

App runs on http://localhost:3000

## Features

- Role-based auth via Supabase (super_admin, admin, employee)
- CRM: Leads, Contacts, Deals, Tasks (persisted in Supabase Storage)
- Website admin (projects, team, launch settings) for super users
- User management (create/edit/delete, email & password) for super users
- Dark/light toggle with glassmorphism design
- Mobile-optimized responsive layout
